# Neotime — versions publiées

Neotime est le chrono de Neoffice dans la barre des menus (Mac) et la zone de notification (Windows).

Ce dépôt ne contient que les installeurs et les fichiers que Neotime lit pour se mettre à jour tout seul. Le code source est privé.

## Installer

Prendre la dernière version dans [Releases](https://github.com/bvisible/neoffice-desktop-releases/releases/latest).

- **Mac** : le `.dmg` de votre processeur, `arm64` pour Apple silicon (M1 et suivants), `x64` pour Intel. La version est signée mais pas encore notarisée : à la première ouverture, Réglages Système › Confidentialité et sécurité › « Ouvrir quand même ».
- **Windows** : `neoffice-desktop-<version>-setup.exe`. Windows peut afficher « Windows a protégé votre ordinateur » : « Informations complémentaires », puis « Exécuter quand même ».

Une fois installé, Neotime vérifie les nouvelles versions au démarrage et se met à jour seul.
